HAR Analyzer

Privacy Policy

Effective date: August 16, 2026

HAR Analyzer processes network trace data locally in your browser. The extension does not send your HAR files, captured requests, diagnostics, or generated briefs to the developer or to an external analysis service.

1. Data the extension handles

HAR Analyzer handles data only when you choose to upload a HAR/JSON file or start live capture for the current browser tab. Depending on the source, this data may include:

  • page URLs, request URLs, domains, paths, and redirect targets;
  • HTTP methods, status codes, resource types, sizes, and timing information;
  • request and response headers;
  • the current page title and URL;
  • diagnostics and a developer brief derived from that network trace.

HAR files and HTTP headers can contain sensitive values, including query parameters, cookies, authorization headers, session identifiers, or other information added by a website. Review a HAR file before sharing it with anyone.

2. How the data is used

The data is used solely to provide the extension's user-facing purpose: displaying and analyzing the network trace you selected, identifying request errors and performance issues, grouping domains, and generating a copy-ready brief.

Live capture starts only after a user action and is limited to the tab where HAR Analyzer was opened. The extension does not use network data for advertising, profiling, credit decisions, or unrelated analytics.

3. Local processing and retention

Analysis is performed locally by the extension. The normalized workspace for each analyzed tab is stored in chrome.storage.session so it can survive a Manifest V3 service worker restart during the current browser session.

You can remove the current workspace with the Clear action. Closing the analyzed tab removes its workspace, closing the browser session clears session storage, and uninstalling the extension removes its extension storage through Chrome.

4. Data sharing and sale

HAR Analyzer does not transmit network trace data to the developer, does not share it with third parties, and does not sell user data. No external AI or backend analysis API is used in the current version.

The developer does not have access to or allow humans to read the HAR files, captured requests, diagnostics, or briefs processed inside your browser.

5. Permissions

  • activeTab and scripting allow the extension to collect performance entries for the page you chose to analyze.
  • webRequest and host access allow user-initiated live capture of request metadata and headers on supported HTTP/HTTPS pages.
  • sidePanel displays the analyzer interface.
  • storage retains the tab workspace in Chrome session storage.

6. Website hosting

This Privacy Policy, the HAR Analyzer Welcome Page, and the Uninstall Page are hosted by GitHub Pages. GitHub may process standard connection information under the GitHub General Privacy Statement.

The Welcome Page and Uninstall Page use Umami Cloud to measure anonymous page views and distinguish the two page paths. Umami may process the page path and title, referrer, browser, operating system, device and screen type, browser language, and approximate location derived from the request. URL query and hash parameters are excluded, the tracker respects the browser's Do Not Track setting, and no custom events or identifiers are sent. Umami does not use cookies; the visitor's IP address is used to derive analytics metrics but is not stored. HAR Analyzer does not send HAR files, captured requests, diagnostics, generated briefs, form responses, names, or email addresses to Umami. See the Umami Privacy Policy.

7. Voluntary uninstall feedback

After HAR Analyzer is removed, Chrome may open an Uninstall Page containing an embedded Google Form. The page states that removal is already complete and that feedback is optional.

The form asks one open-ended question and does not request your name or email address. Loading the embedded form sends standard connection information to Google, and submitting it sends the response text to Google Forms and makes it available to the developer. Do not include HAR files, URLs, headers, cookies, tokens, or other sensitive information. Google's processing is governed by the Google Privacy Policy.

8. Chrome Web Store Limited Use

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

9. Changes to this policy

If the extension's data practices change, this policy and any required in-product disclosures will be updated before the changed practices are introduced. The effective date at the top of this page identifies the current version.

10. Contact

Questions about this policy or HAR Analyzer can be submitted through the HAR Analyzer support issue tracker. Do not include HAR files, authorization headers, cookies, tokens, or other sensitive data in a public issue.
